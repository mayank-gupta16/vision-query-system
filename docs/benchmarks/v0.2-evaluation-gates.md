# v0.2 frozen evaluation gates

Issue [#64](https://github.com/mayank-gupta16/vision-query-system/issues/64)
freezes `v0.2-gates-1` before detector research begins. Issue #21's licensing
review then added the non-numeric `v0.2-gates-2` amendment without changing any
dataset, metric, threshold, repetition, statistic, profile, or waiver. The normative rationale,
threshold table, receipt phases, `UNKNOWN` behavior, waiver boundary, and
amendment process are in
[ADR-0006](../decisions/ADR-0006-v02-evaluation-gates.md). This page is the
operator route to the machine contracts.

## Files and boundary

- [`policy.json`](../../fixtures/v02-evaluation/policy.json) defines CPU-LITE,
  repetitions/seeds/statistics, eligible licenses, the four experiment strata,
  metric calculation identifiers, absolute thresholds, directions, and
  per-metric regression budgets.
- [`policy-v0.2-gates-2.json`](../../fixtures/v02-evaluation/policy-v0.2-gates-2.json)
  binds `v0.2-gates-1` by digest and adds exact runtime license-evidence hashes,
  the reviewed license expressions, and the explicit no-distribution-approval
  boundary used by issue #21.
- [`detection-manifest.json`](../../fixtures/v02-evaluation/detection-manifest.json)
  is a generated rights/privacy-safe minimal manifest.
- [`detection-receipt.json`](../../fixtures/v02-evaluation/detection-receipt.json)
  is a passing structural example whose hashes and metric values are contract
  sentinels. It is not a measured detector, approved adapter, or product claim.
- [`evaluate_v02_gates.py`](../../scripts/evaluate_v02_gates.py) is the
  zero-dependency fail-closed evaluator.

The command parses inputs as inert bounded JSON. It never downloads sources,
imports a candidate, opens a URL, executes model code, reads media, or writes
raw predictions. Actual #21–#24 harnesses remain responsible for reproducing
their pinned evaluators from reviewed sources and emitting aggregate-only test
receipts.

## Validate the contract fixture

Use a new private output path; the evaluator refuses to overwrite an existing
path or follow a link:

```sh
validation_root=$(mktemp -d /tmp/visualworld-v02-gates.XXXXXX)
python3 scripts/evaluate_v02_gates.py \
  --manifest fixtures/v02-evaluation/detection-manifest.json \
  --receipt fixtures/v02-evaluation/detection-receipt.json \
  --as-of 2026-09-07 \
  --output "$validation_root/result.json"
```

The terminal receives only `{"status": "pass"}`. The result file binds the
exact candidate and baseline receipt SHA-256 values, candidate/configuration,
policy and dataset digests, runtime/profile, experiment, test split, absolute
decisions, baseline status, failed scopes, and the complete validated waiver
evidence when one applies.

## Selection, regression, and amendments

For `selection`, omit `--baseline`; only absolute gates decide the result. A
candidate that fails can remain a research result or yield an explicit
no-selection conclusion. Do not tune on the test split or weaken this policy to
make a candidate pass.

For `regression`, set the receipt phase to `regression` and provide the frozen
passing selection receipt:

```sh
python3 scripts/evaluate_v02_gates.py \
  --manifest /private/visualworld/manifests/detection-v1.json \
  --receipt /private/visualworld/results/detection-candidate.json \
  --baseline /private/visualworld/results/detection-baseline.json \
  --output /private/visualworld/results/detection-comparison.json
```

The baseline must be unwaived and match the policy, manifest, CPU profile,
evaluation harness, and metric implementation. Adverse changes round toward
failure. Zero-tolerance invariants are rechecked absolutely rather than divided
by zero.

An accepted amendment adds a new policy version, ADR disposition, fixtures, and
tests. The `v0.2-gates-2` amendment is the first instance: it leaves every
numeric rule inherited and changes only candidate/runtime compliance evidence.
Keep the old file and receipts available when evidence cites them. Update
the linked research issues to the new digest; never edit a historic receipt to
look compatible.
