# VisualWorld documentation

Use these indexes to load only the context needed for a task.

- [Product](product/index.md): canonical vision, capabilities, and non-goals.
- [Architecture](architecture/index.md): system boundaries, world data, and ports.
- [Decisions](decisions/index.md): long-lived architecture decisions and ADR template.
- [Project](project/index.md): current state, roadmap, release gates, and GitHub bootstrap.
- [Benchmarks](benchmarks/index.md): profiles, metrics, datasets, and reproducibility.
- [Testing](testing/index.md): test layers and model-adapter strategy.
- [Research](research/index.md): unresolved questions that require measured experiments.
- [Security](security/index.md): threat model, privacy, hostile media, and injection defenses.
- [Legal](legal/index.md): project, dependency, model, and dataset licensing records.

`docs/project/current.md` is the concise session bootstrap. GitHub issues and
milestones remain the source of truth for actionable work once authenticated
infrastructure has been created.
