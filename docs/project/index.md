# Project documentation

- [Current state](current.md) is the concise, canonical session bootstrap.
- [Roadmap](roadmap.md) defines milestone dependencies and boundaries.
- [v0.1 issue plan](v0.1-issue-plan.md) records the design snapshot behind live
  GitHub issues #1–#20; GitHub now owns their status and discussion.
- [Release gates](release-gates.md) defines evidence required for a release.
- [Codex delivery policy](codex-delivery.md) defines resumable milestone
  execution, independent review, merge-count audits, and release verification.
- [v0.1.0 release record](v0.1-release.md) freezes the first shipped boundary,
  gate evidence, P1 waiver, reproduction path, and v0.2 handoff.
- [GitHub bootstrap](github-bootstrap.md) separates prepared repository files
  from unverified live settings.

Once created, GitHub milestones and issues are the source of truth for work
state. These docs capture durable architecture and release intent, not daily
task logs.
