# v0.1 actionable issue plan

These staging IDs were materialized one-to-one as GitHub issues #1–#20 on
2026-09-06. GitHub owns their live status and discussion; this document preserves
the reviewed dependency design. Add `agent:ready` only after decisions,
dependencies, and the temporary contribution-license gate are resolved. One PR
should normally close one issue.

## V01-01 — Bootstrap product, architecture, and repository governance

- **Labels:** `type:docs`, `area:docs`, `area:infra`, `priority:P0`
- **Problem:** an empty repository cannot guide safe, resumable work.
- **Scope/non-goals:** indexed docs, AGENTS/current state, roadmap, security/legal
  policy, templates, CODEOWNERS, policy CI; no application implementation.
- **Dependencies:** none.
- **Acceptance/tests:** local validator, YAML parse, current-tree secret heuristic,
  separate full-history secret/large-object audit; a fresh session orients from
  AGENTS, current state, active issue, and indexed docs.
- **Benchmark/security/done:** benchmark N/A; immutable least-privilege CI; live
  settings verified separately; focused reviewed PR merged.

## V01-03 — Select the application toolchain and lock strategy

## V01-04 — Select media runtime and hostile-input isolation

- **Labels:** `type:research`, `area:video`, `type:security`, `priority:P0`
- **Problem:** decoding malformed/untrusted video creates parser, traversal,
  decompression, SSRF, and resource-exhaustion risk.
- **Scope/non-goals:** probe/decode candidates and licenses, argument-array API,
  non-root process boundary, filesystem/network/resource limits, cancellation,
  supported local platforms; no production adapter.
- **Dependencies:** V01-03.
- **Acceptance/tests:** bounded experiment on malformed/oversized media; platform
  capability matrix; residual risks/waiver route; accepted ADR.
- **Benchmark/security/done:** CPU-LITE startup/throughput/RSS overhead recorded;
  selected runtime/build/codecs entered in legal inventory.

## V01-05 — Decide ingestion records, identifiers, and rational time model

- **Labels:** `type:research`, `area:world-model`, `priority:P0`

- **Scope/non-goals:** Source, FrameRef, Geometry, EvidenceRef, RunManifest,
  versioning, fingerprints, rational PTS, measured/estimated tags; defer

- **Dependencies:** V01-01 and V01-03.

- **Benchmark/security/done:** size/serialization estimate and untrusted-field limits;

## V01-06 — Decide local metadata/artifact storage and deletion protocol

- **Labels:** `type:research`, `area:storage`, `priority:P0`
- **Problem:** metadata/artifact consistency, privacy deletion, and recovery cross stores.
- **Scope/non-goals:** transactional metadata candidate, migrations, artifact
  hash/layout, staged writes/commit markers, orphan audit/repair, cascade deletion;
  no distributed/vector storage.
- **Dependencies:** V01-05 and relevant V01-03 outcomes.
- **Acceptance/tests:** crash scenarios and sequence diagrams, privacy consequences,
  alternatives, migration/version plan, accepted ADR.
- **Benchmark/security/done:** estimated index/hash/write overhead; no video blobs in
  metadata DB; ADR merged before store implementation.

## V01-07 — Create synthetic fixture generator and rights manifest

- **Labels:** `type:test`, `area:benchmark`, `priority:P0`
- **Problem:** source/probe/sampling/geometry work needs legal deterministic evidence.
- **Scope/non-goals:** source-code generator for tiny CFR/VFR-like fixtures,

- **Dependencies:** V01-02, V01-03, V01-04.

## V01-10 — Define v0.1 ports and instrumented deterministic fakes

- **Labels:** `type:feature`, `area:infra`, `priority:P0`

## V01-11 — Implement the bounded local video source/probe adapter

- **Labels:** `type:feature`, `area:video`, `priority:P0`
- **Problem:** ingestion needs accurate metadata and rational timestamps.
- **Scope/non-goals:** local fingerprint, dimensions/duration/codec/rotation/time
  base/PTS, structured errors through accepted isolated runtime; no remote/RTSP.
- **Dependencies:** V01-04, V01-07, V01-09, V01-10.
- **Acceptance/tests:** synthetic CFR/VFR/rotation plus corrupt/oversize/timeout,

- **Benchmark/security/done:** CPU-LITE probe wall/RSS; non-root constrained decode,
  argument arrays only; VideoSource contract passes and merged.

## V01-12 — Implement deterministic PTS-aware frame sampling

- **Labels:** `type:feature`, `area:video`, `priority:P0`
- **Problem:** frame-index/FPS arithmetic is wrong for many sources.
- **Scope/non-goals:** configurable near-5-FPS policy over source PTS, deterministic
  ordering, bounded memory, cancellation/resume; no adaptive motion sampling.
- **Dependencies:** V01-11.
- **Acceptance/tests:** stored timestamp equals decoded PTS with zero rational
  conversion loss; selection error follows documented nearest-eligible-frame/CFR/
  VFR-gap policy; repeated/resumed sample identities match.
- **Benchmark/security/done:** CPU-LITE throughput/RSS and duration/frame caps;
  FrameSampler contract and goldens pass and merge.

## V01-13 — Implement original-pixel geometry and deterministic crop extraction

- **Labels:** `type:feature`, `area:geometry`, `area:evidence`, `priority:P0`
- **Problem:** resized coordinates must resolve to trustworthy source pixels.
- **Scope/non-goals:** source/detector transforms, rotation, round/clamp policy,
  deterministic manually/fake-specified region and original-resolution crop;
  no detector/segmentation/best-frame scoring.
- **Dependencies:** V01-07, V01-09, V01-11.
- **Acceptance/tests:** aspect/edge/invalid/rotation property tests and synthetic
  pixel goldens map within one source pixel.
- **Benchmark/security/done:** copy/CPU/RSS measured; crop destination cannot escape
  artifact root; sensitive pixels never logged; merged.

## V01-14 — Implement the accepted local EvidenceStore design

- **Labels:** `type:feature`, `area:evidence`, `area:storage`, `priority:P0`

- **Dependencies:** V01-06, V01-09, V01-10.
- **Acceptance/tests:** contract, idempotency, collision/error, interrupted write,
  symlink/traversal, store-local delete and audit tests.
- **Benchmark/security/done:** disk/hash/write cost; artifacts local and logs redact
  content; on-disk version documented and merged.

## V01-16 — Coordinate an evidence-safe ingestion run and recovery protocol

- **Labels:** `type:feature`, `area:infra`, `priority:P0`
- **Problem:** independent stores/stages cannot prove end-to-end atomicity or deletion.
- **Scope/non-goals:** validated config, state machine, staged writes/commit markers,
  orphan repair, cascade deletion, versions, structured logs/errors/timings,
  manually/fake-specified region producing retrievable original-pixel evidence;
  no real detector/tracker/semantic call.
- **Dependencies:** V01-12, V01-13, V01-14, V01-15.
- **Acceptance/tests:** fake vertical run, crash at every commit boundary, retry,
  repair, complete deletion, deterministic manifest and no partial success.
- **Benchmark/security/done:** stage costs; zero default egress; logs contain IDs/
  hashes/status, not pixels/OCR/prompts/secrets; golden evidence resolves and merged.
