# VisualWorld v0.1.0 release record

VisualWorld v0.1.0 is the first experimental release, dated 2026-09-07. The
canonical tag is `v0.1.0`; the corresponding GitHub Release publishes the
reviewed universal wheel, source distribution, runtime-only CycloneDX 1.6 SBOM,
and SHA-256 checksum file. No package registry is used.

## Shipped boundary

The release contains version-1 deterministic ingestion records and ports, a
bounded Linux local-video library adapter, exact-PTS sampling, exact
detector/source coordinate mapping and byte-preserving RGB24 crops, local
content-addressed evidence storage, transactional SQLite world metadata,
crash-safe fake/manual ingestion coordination, source deletion, and a
canonical-JSON CLI for the built-in fixture.

The supported CLI data path is deliberately the deterministic built-in 2×2
fake/manual fixture. v0.1.0 does not claim real-video CLI ingestion, object
detection, tracking, OCR, VLM/ReID, persistent entities, natural-language or
structured world queries, live streams, model accuracy, or a package-registry
distribution. Public Python interfaces are experimental before v1.0.

## Release gates

- Required implementation issues #1–#19 closed before the release ticket.
- Both supported CPython versions pass strict formatting/linting, mypy, 556
  tests, 90% branch coverage, license-inventory checks, and repository policy on
  Linux x86_64 and macOS arm64 CI.
- The package builds from a hash-constrained sdist, installs into a fresh
  runtime, contains only the reviewed modules and Apache-2.0 license, exercises
  the module and console entry points plus exact-crop quickstart, and produces a
  zero-third-party-runtime-dependency SBOM. The deliberate invalid build-backend
  hash is rejected.
- The hashed locked development dependency graph has no known vulnerabilities.
  Runtime dependencies, models, datasets, external media, and services are all
  absent, so no associated distributable license or privacy exception exists.
- The [v0.1 CPU-LITE application baseline](../benchmarks/v0.1-cpu-lite-baseline.md)
  passes all exact functional/resource checks at 1.978 seconds wall time,
  30.334× real time, 46,694,400-byte peak RSS, and 4,120,576-byte logical store
  size. The 2 GiB peak-RSS gate and compatible-result comparator pass.
- The release-gate regression suite covers successful reopen/retry/delete,
  interrupted recovery, corrupt/oversized/path/link/injection/redaction cases,
  and denied network/process egress using only generated Apache-2.0 bytes.

## Reproduce

From the tagged checkout, use the checksum-verified managed CPython 3.13.15
reference lane:

```sh
python3 scripts/bootstrap.py --python 3.13.15
python3 scripts/dev.py sync --python 3.13.15
python3 scripts/dev.py check --python 3.13.15
python3 scripts/dev.py build --python 3.13.15
python3 scripts/dev.py audit --python 3.13.15
```

Repeat bootstrap, sync, check, and build with `--python 3.14.7`. The GitHub
Release notes bind the final tag/commit, CI run, exact benchmark comparison,
asset sizes/hashes, SBOM hash, security/license/privacy review, and independent
reviewers. The assets can be verified with the attached `SHA256SUMS` file before
installation.

## Resume at v0.2

The next milestone begins with research issues #21–#24: choose a CPU-conscious
detector/runtime against measured accuracy per CPU-second, calibrate sampling
recall, quantify original-resolution crop value, and evaluate tracking under
cuts/occlusion/moving cameras. Only after those thresholds and license/privacy
constraints are ratified should epic #30 be decomposed into shipped adapter and
tracklet work. The v0.1 records, stores, evidence, and benchmark contracts are
the stable foundation; they do not pre-decide a model or runtime.
